# #406 — VST3 SDK licence settled: MIT via JUCE 8.0.14

*2026-09-17T03:12:39Z*

The issue asked us to pick between Steinberg's proprietary VST3 agreement and the SDK's GPLv3 arm. Neither exists any more: from SDK 3.8 Steinberg licenses VST3 under MIT and has withdrawn both other options. JUCE 8.0.11 was the first JUCE to bundle SDK 3.8.0, so the fix is a JUCE pin bump from 8.0.9 to 8.0.14 (still JUCE 8, same EULA as #369) plus recording the decision.

## Known limitations

- **No VST Compatible logo.** Optional under MIT; adopting it commits every page and doc that says "VST" to carrying it. Recorded as a stance in `LICENSE.md`, to be revisited when there is a product site.
- **JUCE's other bundled notices (FLAC, Ogg Vorbis, zlib, pnglib, HarfBuzz…) are not yet audited** for what a binary distribution must reproduce. `THIRD_PARTY_NOTICES.md` says so; that audit belongs to the first public build.
- **Nothing ships yet**, so the notice file has no installer to ride in. It is the source of truth for when one exists.
